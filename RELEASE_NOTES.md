Quick notes from your Mac menu bar, now with one-click updates.

- Choose **Update & Restart** in **Settings → About Slip → Updates** to download, install and reopen the latest version.
- Updates verify the download and app signature, follow Slip’s normal save-and-quit flow, and restore the previous app if reopening fails.
- Your notes, folders, tags, settings and backups stay in place.
- A simpler README header puts menu bar note-taking first.

**Install:** `brew install --cask berkinduz/tap/slip`, or download the DMG and drag **Slip → Applications**.

**Compatibility:** macOS 14 or later, Apple Silicon. The app is ad hoc signed and not notarized; see [Apple’s opening-app guidance](https://support.apple.com/en-us/102445) if macOS blocks the first launch.
