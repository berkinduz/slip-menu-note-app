Quick notes, readable Markdown, and small to-dos in your Mac menu bar.

- Organize notes in independent folders and nested folders. Create, rename, move, and remove folders while keeping note content and tags intact.
- Use manual tags across folders through the note footer and a compact Tags browser.
- Pin the panel from its header to keep it open when switching apps. Note pinning remains available separately in note menus.
- Keep the sidebar in the state you left it, including after a restart.
- Use a neutral Kanagawa Dragon `/` menu and normal English UI labels; user-entered text keeps its original case.
- Capture quickly with optional titles, clickable task lists, local autosave, and Markdown export.

Download the ZIP, unzip it, and move `Slip.app` to Applications. See the [README](https://github.com/berkinduz/slip-menu-note-app#quick-install) for usage and shortcuts.

**Compatibility:** macOS 14 or later, Apple Silicon. This build is ad hoc signed and is not notarized; macOS may show a first-launch warning. Apple's [opening-app guidance](https://support.apple.com/en-us/102445) explains the available options.

Existing note libraries upgrade automatically. Notes, tags, titles, pins, and Trash are preserved; existing tags do not create folders.

Contributions, bug reports, and focused UI improvements are welcome.
